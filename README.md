

# Student Assignment Tracker

## Project Overview
Student Assignment Tracker is a simple web application that helps students manage and keep track of their assignments.

## Features
- Add assignments by subject and title
- Set assignment due dates
- View pending and completed assignments
- Update assignment status
- Delete assignments
- Save data using LocalStorage

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

## Project Purpose
This project was created to practice front-end web development and JavaScript programming.

## Project Type
Individual Project
